# 🛡️ Security Policy — دژ مسنجر

## Supported Versions | نسخه‌های پشتیبانی‌شده

| Version | Supported |
|---------|-----------|
| 1.4.x   | ✅ Yes     |
| < 1.4   | ❌ No      |

---

## Reporting a Vulnerability | گزارش آسیب‌پذیری

**🇮🇷 فارسی:**  
لطفاً مشکلات امنیتی را **هرگز** به صورت عمومی در Issues مطرح نکنید.  
برای گزارش آسیب‌پذیری، از طریق دایرکت کانال StarryNight Studio اقدام کنید.

**🇬🇧 English:**  
Please **do NOT** open public GitHub issues for security vulnerabilities.  
Report privately via the StarryNight Studio channel direct message.

---

## Scope | محدوده

- WebView sandbox bypass
- Unauthorized file system access
- Data leakage between messenger instances
- Permission escalation

## Out of Scope

- Issues in third-party messenger apps loaded inside Dezh
- UI/UX bugs (use regular Issues)
